# Vintage Lite · сервер ключей

Нужен домен с DNS-записью на VPS, открытые порты 80/443 и Docker с Compose. Если эти порты заняты другим сайтом, подключите API к существующему HTTPS-прокси вместо запуска второго Caddy.

1. Скопируйте папку license-server на VPS и перейдите в неё.
2. Создайте конфигурацию, подставив свой домен:
   
   ```sh
   umask 077
   printf 'LICENSE_DOMAIN=%s\nADMIN_PASSWORD=%s\n' 'keys.example.com' "$(openssl rand -hex 32)" > .env
   docker compose up -d --build
   ```
3. Откройте https://ВАШ-ДОМЕН/admin. Логин admin, пароль ADMIN_PASSWORD из .env. Выпустите ключ и скопируйте его при создании. В списке останутся только последние восемь символов.
4. В ThreeOneOSFive/Info.plist укажите полный HTTPS-адрес своего домена в строке сразу после LicenseServerURL. Затем соберите и подпишите новую IPA. Пустой адрес блокирует вход.
5. Проверьте вход с одним ключом на двух iPhone при лимите 1, затем отзыв ключа. Перед Apply Patch приложение обращается к API; во время работы перепроверяет доступ каждые 30 секунд. После возврата из фона также нужна проверка. Вход после полного перезапуска требует повторного ввода ключа.

Срок общего ключа начинается с первой успешной активации для всех устройств одновременно, либо завершается в указанную фиксированную дату UTC. Блокировка устройства освобождает место и запрещает этому идентификатору повторный вход по тому же ключу. iOS предоставляет identifierForVendor: после переустановки он может измениться. Смена телефона требует управления местами через админку.

База SQLite хранится в томе licenses. Для резервной копии остановите сервис api и сохраните том. Файл .env содержит пароль администратора и не должен попадать в Git. Старая офлайн-IPA не обращается к серверу и не подчиняется отзыву новых ключей.
